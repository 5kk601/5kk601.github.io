# Xihui Wu personal homepage

Static personal homepage covering multimodal AI research, engineering experience, and selected work.

Website: https://5kk601.github.io/

## Local preview

Run `python -m http.server 8765` from this directory and open `http://localhost:8765`.

## Files

- `index.html`: profile, research, experience, projects, education, and contact links.
- `styles.css`: responsive layout and mobile navigation styles.
- `assets/XihuiWu-CV.pdf`: current two-page CV.
- `assets/xihui-anime.png`: AI-generated illustrated portrait based on the owner's supplied photograph.
- `.nojekyll`: serves the static files directly on GitHub Pages.

No build step, external analytics, or server-side dependencies are required.
